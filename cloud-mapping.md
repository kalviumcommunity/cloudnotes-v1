# Local to Compute Engine Mapping

| Local Machine | Google Compute Engine | Reason |
|--------------|----------------------|--------|
| Ubuntu on WSL | Ubuntu VM | Same operating system |
| localhost | External IP | Public access |
| Gunicorn | Gunicorn | WSGI server |
| systemd | systemd | Service management |
| Nginx | Nginx | Reverse proxy |
| SQLite | SQLite | Lightweight database |
| Virtual Environment | Virtual Environment | Dependency isolation |
